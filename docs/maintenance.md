# Documentation maintenance

This is an independently maintained community edition of Koinos documentation. The initial pages were imported on September 30, 2026. Import and build checks do not constitute a new technical audit or proof of node readiness.

## Source baselines

The service references cite immutable service commits and `koinos-proto` v2.6.0. Their integration configuration is pinned to `koinos/koinos` commit `821674672e699bf56e94d7c0e8bce122e83d1482`. Record exact source revisions, substantive review dates, evidence and remaining uncertainty when updating a page.

The [source baseline record](https://github.com/pgarciagon/koinos-docs/blob/main/maintenance/source-baselines.json) lists all 11 service pages. Its review dates remain unset until a new review is actually performed. Older operational or ecosystem guidance needs checking against the selected target version before use.

## Improve the documentation

Use the [contribution guide](https://github.com/pgarciagon/koinos-docs/blob/main/CONTRIBUTING.md) and [detailed service template](https://github.com/pgarciagon/koinos-docs/blob/main/maintenance/templates/service-reference.md). Architecture explains behavior and interfaces. [Node Operators](nodes/index.md) covers configuration and operational procedures. Keep private and unreviewed material out of public pages.

The [producer-node coordinator](https://github.com/pgarciagon/koinos_legacy_node) tracks inventories, proposals, changes and validation evidence. Keep its version baseline distinct from the documentation baseline until differences have been reviewed.
